# Porsche 930 addition review

The stock Porsche 911 Turbo by Lexyc16 is appended to the garage. Existing car
indices and their shared links remain stable, including the RWB and R8.
The default is graphite; the body, wheels, trim and glass remain separate.

The official glTF archive includes matching CC BY 4.0 attribution. The source
and compressed export retain identical decoded vertex attributes, triangle
topology, texture dimensions and RGBA pixels. The download already supplies
supported metallic/roughness materials, so no material conversion is applied.
Its body material is named for interactive paint discovery. Shared thin-glass
handling and the curated paint are runtime adaptations.

The source comparison uses the portfolio renderer for both files. Desktop,
tablet and narrow-phone reviews check framing, paint controls and lighting.
Viewport emulation does not establish physical-phone compatibility.
