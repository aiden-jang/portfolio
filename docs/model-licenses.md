# Car model licenses

The source code's MIT license does not cover the car assets. This review records
what each model's publisher licenses, plus any upstream notice supplied by that
publisher. The checked source URLs, creator identities and license URLs are in
[the evidence record](model-license-evidence.json). Reviews use Sketchfab’s public model API and download dialogs;
the evidence record preserves each model’s own review date.

## Adaptations and other rights

Web exports use compressed geometry and WebP textures, retaining full mesh detail.
The RWB uses its original full-mesh GLB export; no site mesh simplification is applied.
The M3 and Datsun use vertex reordering and lossless meshopt compression. Original
materials and attribution metadata are retained. Site lighting, framing, curated
paint defaults and optional paint colors are runtime adaptations. Thin glazing uses alpha transparency
in place of refraction for reliable browser rendering, retaining its authored tint
and existing alpha where present.

The R8, Supra A80, stock Porsche 930 and Porsche 917K use Sketchfab's official glTF downloads. Each archive includes a
license.txt matching the creator, model source and CC BY 4.0 license shown in the
listing. Their exports retain the source geometry, floating-point vertex precision,
texture dimensions and decoded texture pixels. glTF Transform 4.4.1 and
meshoptimizer 0.25.0 reorder and losslessly compress geometry; Sharp encodes
lossless WebP textures. The source attribution and a web adaptation notice are
embedded in each GLB. Compare original and optimized renders as well as decoded
geometry when changing these settings.

The R8 retains the author's PBR materials, clearcoat and amber-gold paint, including
separate tires, carbon fiber, glazing and lights. No material workflow conversion
or roughness changes are applied. It is a modified widebody exterior model.

The stock Porsche 930 download already supplies supported metallic/roughness
materials and clearcoat. Its body material is named for paint discovery; its
material response is unchanged. The default graphite paint and shared thin-glass
handling are runtime adaptations.

The official download listings, displayed comments and archive notices were checked for
upstream credits or game extraction. Except for the 917K's credited JUSTGAME source, those listings declare no upstream source.
This establishes the supplied publisher license, not independent proof of authorship
or clearance of manufacturer rights. The evidence record retains the supplied
license text, archive hashes and creator IDs, including older profile aliases.
Asset optimization uses local, deterministic geometry and image tools.

The RWB publisher identifies Porsche AG as the vehicle-design rights holder.
Creator licenses do not grant manufacturer affiliation, trademark rights or a
blanket clearance of vehicle designs. The site credits retain that distinction.

The Porsche 917K uses the selected vecarz red Le Mans export, with JUSTGAME's
upstream credit retained. Its full mesh, source livery, texture pixels and material
parameters are preserved. Its racing livery is fixed: paint controls and repaint
commands are hidden, and shared color links keep the original finish. Shared
thin-glass handling applies.

The proposed Supra GT300 is not included. The vecarz reupload lists CC BY, but the
credited [builder's source](https://sketchfab.com/3d-models/toyota-gr-supra-gt-gt300-58efbe2b2e144d8e8edfcc0c64e55f88)
uses [Free Standard](https://sketchfab.com/licenses), restricting standalone-file
access, and identifies an unlinked downloaded base model. Resolve these terms
before publishing it in the public asset directory or repository.

## Restored M4 source and terms

The G82 M4 ADRO is restored at the owner's request for a personal, noncommercial
portfolio. Its vecarz listing uses CC BY 4.0 and explicitly credits Ddiaz Design.
That credited listing uses CC BY-NC-SA 4.0 and states that it is based on a CSR2
model. The uploader labels do not establish permission for the underlying game
assets; that permission remains unverified.

The web adaptation retains the upstream CC BY-NC-SA terms. Both contributors,
their source links, the upstream license and the source caveat appear in Contact
credits and asset metadata. Other assets and the site's source code retain their
own licenses.

The restored file retains the previous web export's geometry, textures, material
parameters, orientation and node hierarchy. No further compression, simplification
or texture resizing is applied. Only attribution metadata is expanded. The site applies
an Amethyst default paint to the explicitly named body material, preserving the
carbon fiber, wheels and trim. It is appended to the garage to preserve existing
shared model indices and loads only when selected.

## Curated lineup and new exports

The picker order moves from classics through modified road cars to racing:
F40, 300 SL, stock MX-5 NA, Datsun 280Z, E30, Countach 5000 QV, stock Supra A80,
911 RWB, M4 ADRO, Aimgain R35, 911 GT3 RS, Aventador SV, Ferrari F1-75 and RB16B.
The R8, stock 930, 917K, modified GR Supra, standard GT3 and 296 GT3 remain hosted and credited
for older shared URLs, but are
absent from the picker, cycling, randomization and selection commands. Registry
indices stay permanent; display order is independent.

The web exports retain every decoded vertex attribute and triangle,
including the Supra’s detailed interior. Original texture dimensions and RGBA
pixels, material parameters, node hierarchy and Miata animation data are preserved.
Only vertex/triangle reordering, lossless meshopt encoding and lossless WebP
encoding are applied. Exact comparisons and decoded glTF validation report no
errors or warnings. The RB16B uses Sketchfab’s official full-resolution glTF export because the
original upload incorrectly marks solid surfaces transparent and uses mirror-like
tire materials. The official web export supplies opaque tire and carbon materials
and the publisher’s web-viewer material response. It has 240,779 triangles versus
240,827 in the original upload; all geometry, materials and pixels in the chosen
web export are retained without site mesh simplification or texture resizing.

The Miata, GR Supra, 296 GT3 and RB16B use official glTF archives with matching license.txt files.
The GT3 and Aventador use original-format archives without a
license.txt; their download dialogs and public API licenses are recorded instead.
The GT3 and Aventador archives expose Ddiaz Design source metadata, which is
retained alongside the selected publisher’s credits. Their source descriptions
identify CSR2. These records do not establish permission for underlying game
assets. The owner accepts that provenance uncertainty for this personal portfolio.
The GT3 adaptation retains CC BY-NC-SA terms; the selected Aventador and 296 GT3
retain CC BY-NC terms. This does not change the source code’s MIT license.

The 296 GT3 also uses the official full-resolution web export to retain vecarz’s
published material response and wheel treatment, rather than the original file’s
underlying source setup. Its complete mesh is retained. Its diagonal parking pose
is normalized at runtime before framing, without changing vertex data. The site
also corrects the printed body's metallic response, uses neutral transparent
glazing, and offsets the livery surface to avoid overlap artifacts. These runtime
material adjustments preserve the source GLB, decals, geometry and wheel finishes.
The Aventador's named body paint receives a runtime clearcoat and lower roughness.
This retains its source GLB, paint color, textures, wheels and trim materials.
The Miata's embedded headlight animation is sampled by a reversible Lights button;
headlights start raised, with instant pose changes for reduced motion. Warm bulb
emission and lens-mounted lights are added at runtime and fade with the opening
pose; the source geometry, textures and animation remain unchanged.

The repaintable defaults are British Racing Green for the Miata, the source
Solar Orange for the GR Supra, Shark Blue for the GT3 and Verde Ithaca for the
Aventador. Body materials are explicit, protecting wheels and trim. Racing cars
keep their original liveries and hide repaint controls. The F1-75 and RB16B retain
their floors and wings and do not receive synthetic road-car headlights or taillights.
Both F1 cars have a custom runtime DRS control using their existing rear-wing
joints; neither source supplies an animation clip. The Supra A80’s Flash control
isolates front lamp triangles at runtime, preserving its shared rear lamp surfaces.
These adaptations do not alter the hosted GLBs, textures or attribution.
Heavy models load only on selection; the arrival prefetch pool is unchanged.

The Ferrari F1-75 occupies the 296 GT3's picker slot alongside the RB16B. It is
appended to the permanent registry, so existing 296 GT3 links retain that car.
The F1-75 preserves its red racing livery, wings and floor;
paint changes and synthetic road-car lights are disabled.

The selected official full-resolution glTF export contains 271,552 triangles,
compared with 271,558 in the original upload. Every triangle and decoded vertex
attribute in the selected export is retained, with exact texture dimensions and
RGBA pixels. Lossless meshopt and verified lossless WebP encoding reduce the
reference GLB from 20,792,388 to 13,552,428 bytes. Decoded validation reports no
errors or warnings. The source has no animation clips. At runtime, painted livery,
printed decals and carbon use dielectric response, and tires use rough nonmetallic
rubber. These material corrections retain source colors and maps, wheel hardware,
the source GLB material definitions and all geometry.

The downloaded license file and current public API agree on CC BY-NC-SA 4.0.
The adapted model retains that license, with credits in the site, embedded
metadata and [the accompanying license notice](../public/models/ferrari-f1-75.LICENSE.txt).
The publisher identifies community-sourced assets and does not establish original
authorship; that provenance uncertainty remains recorded. The source code stays MIT.

## Updating the review

Check the original model and any credited upstream sources, not just a free-download
label or an embedded metadata field. Record the publisher identity and exact
license URL in the evidence record, update the displayed credits, and preserve
original copyright notices. Recheck a replacement asset before publishing it.

## Road paint rendering

The F40, 300 SL, Datsun 280Z, E30, A80 Supra, Miata, RWB and M4 ADRO receive a
runtime gloss adjustment limited to their verified body paint material. Base
roughness is capped at 0.24 with full clearcoat and coat roughness capped at 0.06;
sharper authored coats are retained. Colors, metalness, maps, geometry and the
source GLB files stay intact. Other material finishes retain their authored
settings. Existing license requirements and attribution continue to apply.
